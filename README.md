# IDEA/FIELD: AI Project Evaluator

A web app that helps students turn early project ideas into competition-ready projects. Submit an idea and get grounded feedback, a readiness score, and a practical plan you can build.

## Live Demo
https://ai-project-evaluator--swathilakshmi25.replit.app

## Features
- **New evaluation:** submit a project idea and get it assessed
- **History:** review all your past evaluations
- **Analytics:** track your average readiness score and progress
- **Compare ideas:** see two or more ideas side by side
- **Student profile:** feedback tailored to your background

## How It Works
1. Enter your project idea
2. The app evaluates feasibility and readiness
3. You get a score, feedback, and a clear next step
